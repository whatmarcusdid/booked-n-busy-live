# Book Service Design System

## Overview

Sources (2026-10-13): Figma `Ynb50VwCrK1sOh77Tzkxv3` page "Branding", plus live computed styles
from **bookservice.tech** (built with **Figma Sites**, compiled Tailwind v4.1.3, no exposed brand
variables) and **my.bookservice.tech** (**Next.js** + Turbopack, Tailwind v3, shadcn/ui default
"slate" HSL theme variables that the brand UI mostly bypasses with arbitrary hex classes).
Public app pages: `/audit`, `/book-call`, `/signin`. The logged-in app is **not built yet (deferred)**.

**Light mode only** (no dark mode; ignore shadcn `.dark`). **Live site wins over Figma.**

`design/tokens/tokens.json` is the only source of values. `design/tokens/tokens.css` is generated by
`python3 design/tokens/build.py`. The front matter above is a lint mirror.

## Colors

Always `var(--color-…)`. Full list and provenance in `tokens.json`.

| Role | Token | Notes |
|---|---|---|
| CTA bg | `--color-brand-primary` / `-hover` | Green. Text on it: `--color-text-on-primary` |
| Brand / app action / focus | `--color-brand-secondary` / `-hover`, `--color-focus-ring` | Indigo |
| Dark section | `--color-bg-dark` + `--color-text-on-dark` | |
| Footer / dark surface | `--color-bg-footer` | Distinguishes from bg-dark |
| Page / card / nav | `--color-bg-canvas`, `--color-bg-surface`, `--color-bg-nav` | |
| Text | `--color-text-strong`, `--color-text-body`, `--color-text-muted` | |
| Headings | `--color-text-heading` | Brand navy, distinct from text-strong |
| Borders | `--color-border-default`, `--color-border-input` | border-input aliases text-muted |
| Error | `--color-feedback-error` | No success/warning/info tokens exist |
| Shadows | `--color-shadow-card`, `--color-shadow-soft` | Used in shadow.* composite tokens |

Gradients `--gradient-gradient-1..3` are decorative only (Figma adds a WebGPU mesh overlay CSS can't match).

### Contrast (WCAG 2.x, computed)

| Pair | Ratio | AA text |
|---|---|---|
| text-strong / surface | 20.1 | Pass |
| text-body / surface | 15.5 | Pass |
| text-muted / surface | 7.7 | Pass |
| on-dark on secondary / secondary-hover | 11.4 / 13.9 | Pass |
| input border (`text-muted`) / surface | 7.7 | Pass 3:1 UI |

Fails: `brand-primary` on light surfaces 1.9:1 (never as text/icon/border there); `brand-secondary` on `bg-dark` 1.7:1. Button pairs are in Components.

## Typography

- Headings: Ratch Bold (`--font-family-display`), tracking −1% of size. Body/UI: Inter.
- Scale (tokens `typography.*`): display-2xl 60/72 · display-xl 52/62.4 · display-lg 40/48 ·
  display-md 32/38.4 · display-sm 24/28.8 · display-xs 20/24 · title-lg Inter 600 20/30 ·
  body-xl 24/36 · body-lg 18/27 (marketing default) · body-md 16/24 · label 600 14/21 ·
  body-sm 14/21 · caption 12/18 · tagline (logo only).
- Line height is 1.5× for Inter, 1.2× for Ratch. Use the composite tokens, not ad-hoc sizes.

## Layout

- 4px base (`--space-*`: 4, 6, 8, 10, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 120, 140, 160).
  Common gap values: 16, 24, 8. Label-to-field gap: 6px (`--space-6`). Desktop section padding uses 120–160 vertical, 140 horizontal.
- Container max `--size-container-max` (80rem).
- Breakpoints (`breakpoint.*`): sm 640, md 768, lg 1024, xl 1280, 2xl 1536. Marketing only uses 640/1024.
- Flex/grid with `gap`; no absolute positioning outside decorative art.

## Elevation & Depth

`--shadow-card` (marketing cards), `--shadow-soft`, `--shadow-raised`. `--shadow-card-app` is a
near-duplicate pending decision. No dark-mode shadows.

## Shapes

`--radius-md` 6px (inputs, nav items), `--radius-lg` 8px (buttons, cards, default),
`--radius-xl` 12px, `--radius-2xl` 16px (app), `--radius-full` (pills), `--radius-sm` 4px.

## Components

No Figma components exist; specs below come from live CSS, resolved to tokens (`component.*` in tokens.json).

### Button — primary (solid)
Use for the main action, including **Sign In** (replace the live green-outline Sign In).
| State | Tokens | Contrast |
|---|---|---|
| default | bg `brand-primary`, text `text-on-primary` | 10.0:1 AA |
| hover | bg `brand-primary-hover` | 8.6:1 AA |
| focus-visible | 2px ring `component-focus-ring-color` (secondary), 2px offset; on dark use `ring-color-on-dark` (primary) | ring 11.4:1 on surface, 10.0:1 on dark |
| disabled | bg `bg-disabled`, text `text-disabled`, `cursor: not-allowed` | 5.3:1 (exempt anyway) |
Shared: `radius-lg`, padding `space-8`×`space-24`, `body-md-bold`, height `control-sm`.

### Button — secondary (outline)
Transparent fill, 2px border, text same color as border.
| Surface | Border + text | Hover | Contrast |
|---|---|---|---|
| light (`surface`/`canvas`/`nav`) | `brand-secondary` | `brand-secondary-hover` | 11.4 / 10.9 / 11.1:1 (hover 13.9) |
| dark (`bg-dark`) | `brand-primary` | `brand-primary-hover` | 10.0:1 (hover 8.6) |
Green outline on light **fails** (1.9:1), so light surfaces use **Secondary** (indigo). Focus and
disabled match primary (disabled: border `bg-disabled`, text `text-disabled`, 7.7:1 on surface).
Never put the indigo outline on `bg-dark` (1.7:1).

### Input (standard)
Standardized on live `/book-call`: bg `surface`, text `text-strong`, placeholder `text-muted`,
border `--component-input-border-width` (1px) `--component-input-border` (aliases `text-muted`, 7.7:1 on surface), 
`radius-md`, height `control-lg` (48px), padding `space-12`×`space-16`, `body-sm`; label above in `label` 
with `--component-input-label-gap` (6px).
- focus: border `brand-secondary` + focus ring (below). error: border + message `feedback-error`
  (4.8:1 on surface). disabled: bg `bg-disabled` (live used Tailwind gray-100; confirm).

### Focus ring (all interactive elements)
`:focus-visible` → 2px ring `--component-focus-ring-color` (= `brand-secondary`), 2px offset
(live `ring-2 ring-offset-2 ring-[#2920a5]`). On `bg-dark` use `--component-focus-ring-color-on-dark`.
Replaces the other live ring colors.

## Do's and Don'ts

- Do use tokens only; don't hardcode hex/px/fonts (the live app's arbitrary `bg-[#…]` classes are the anti-pattern).
- Do put `text-on-primary` (bg-dark) on green; don't use pure black (marketing does).
- Do give every interactive element hover, focus-visible (standard ring), disabled.
- Don't use any `deprecated.*` (TradeSiteGenie) color or name.
- Do set Inter on all UI text; don't let buttons/nav fall back to system fonts.
- Don't use green text/borders on light backgrounds; don't use indigo on bg-dark.
- Don't invent spacing, radius, shadows or type sizes; propose them in Figma first.
