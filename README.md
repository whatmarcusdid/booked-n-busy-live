# booked-n-busy-live

Live booking product, built with Next.js and deployed on Vercel.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Supabase

Copy `.env.example` to `.env.local` and add your project URL and anon key from Supabase **Project Settings → API**.

On Vercel, add the same two variables in **Project Settings → Environment Variables**, then redeploy.
